# Product Definition

## Product

Virtual Companion is an AI-powered companion that exists inside a persistent virtual world. The companion can speak with the user, remember meaningful details, perform everyday activities, and react naturally to the user's return.

## Core Experience

The product should feel like a relationship with a living virtual character rather than a conventional chat interface.

### Example

A user opens the app after several days away. Their companion may be sleeping. The companion notices the user, wakes up, approaches them, and says something appropriate to the time apart.

The user can then speak naturally. If the user mentions reading a book, the companion can discuss it, offer a quiz, and eventually place the book in the shared virtual library.

## Product Principles

1. Presence over chat: the companion exists in a world even when the user is not actively talking.
2. Memory with purpose: remember meaningful facts, preferences, events, and shared experiences rather than storing everything blindly.
3. Natural interaction: voice should be a first-class interaction mode.
4. Persistent world: the companion has rooms, activities, mood, and time-aware behavior.
5. User-specific personality: the companion adapts to the individual user and their relationship.
6. Small verified releases: each milestone must work before the next layer is added.
7. Privacy by default: no visible email, phone, or password requirement for the initial experience.

## MVP v0.1 Scope

- Anonymous identity through a provider-managed anonymous session.
- First-launch onboarding.
- User name and companion name.
- One cat companion.
- One simple room.
- Basic companion state machine.
- Live voice conversation.
- Conversation transcript and basic memory extraction.
- Persistent user and companion profile.
- Return detection and contextual welcome.

## Out of Scope for v0.1

- Multiple companion species.
- Multiple rooms with navigation.
- Advanced 3D graphics.
- Social features.
- Payments.
- Public profiles.
- Complex account recovery.
- Full book ingestion and library management.

## Success Criteria

MVP v0.1 is successful when a new user can enter the world, name themselves and their companion, speak with the companion, leave, return later, and experience recognition and continuity without manually logging in.
